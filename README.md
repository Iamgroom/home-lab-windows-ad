# Windows Server 2022 Home Lab

A self-built Active Directory lab for hands-on practice with
Windows Server administration, AD, and Group Policy.

## Goals
- Learn AD user, group, and OU management
- Practice GPO creation and troubleshooting
- Build documentation habits for IT work

## Lab Environment
- Host: Ubuntu Studio (Linux)
- Hypervisor: VirtualBox (in progress)
- VMs planned: 1x Windows Server 2022 DC, 1x Windows 11 client
